# CI evidence bridge

tools/ci_failure_evidence.py retrieves exact run-attempt metadata and a bounded complete job inventory through an injected read-only GitHub JSON transport. Job identities, repository, SHA and attempt must match. The default parser accepts bounded plain verbose unittest streams. An explicit case_parser argument can select github_ci_logs.extract_github_cases for timestamped GitHub text logs containing one complete unittest suite. Missing, duplicate, truncated or unsupported case streams produce incomplete evidence. Diagnostic sections are hashed, never executed or returned as raw text. Both older class-only and newer method-qualified unittest identifiers normalize to the same canonical case ID. Multi-suite and structured synthetic JSON logs remain unsupported and hold.

Local validation: PYTHONPATH=src python3 -m unittest discover -s tests/unit -q passed 234 tests (216 main, ten PR45, eight new methods). Initial test invocation omitted PYTHONPATH and had import errors; a new parser regression also exposed the leading diagnostic divider, corrected before the passing run.

Live observation: connected GitHub retrieval of run 40162039633 attempt 1 and its jobs matched repository sovereignmystic92-dot/nexus-v3-sandbox-, revision cff762df8d3c7bcbc759fd66889dc568195a8342 and job 121075444716. Feeding those original decoded responses through the injected bridge produced INCOMPLETE_EVIDENCE, zero findings, complete job inventory and incomplete case evidence. No job logs were read. This demonstrates metadata integration and a safe missing-evidence hold, not live failure diagnosis.

Host transport remains responsible for authenticated retrieval and response-size/time bounds. This bridge adds no token loading, HTTP client, schedule, repair executor or gate promotion. Persistent observation history is now available separately in failure_store.py. The timestamped decoder's retrieved-job readback is documented in github-ci-log-decoder.md and github-ci-log-readback.json. The original PR46 and subsequent PR47 changes were merged through PR45 and main commit bd8e016 passed 258 hosted tests; this predates the decoder revision. Score stays 11/19. A live failing run and automatic retrieval/delivery remain unproven.
